راهنمای اتصال دانگل Bluetooth ELM327

آموزش اتصال، شناسایی پورت COM و تست اطلاعات واقعی خودرو در سیستم‌عامل ویندوز

مرحله اول: آماده‌سازی دانگل و خودرو

وسایل موردنیاز:

  • دانگل Bluetooth ELM327
  • خودروی دارای پشتیبانی OBD-II
  • کامپیوتر ویندوزی مجهز به بلوتوث
  • Python نصب‌شده روی ویندوز

مراحل اتصال دانگل

  1. محل درگاه OBD-II خودرو را پیدا کن.
  2. دانگل را به درگاه متصل کن.
  3. سوئیچ خودرو را روی حالت ON قرار بده.
  4. چراغ‌های روی دانگل را بررسی کن.
برای Pair کردن معمولاً روشن بودن سوئیچ کافی است. برای دریافت اطلاعات RPM باید موتور روشن باشد.

مرحله دوم: اتصال بلوتوث به ویندوز

  1. وارد Settings ویندوز شو.
  2. بخش Bluetooth & Devices را باز کن.
  3. بلوتوث را روشن کن.
  4. روی Add Device کلیک کن.
  5. گزینه Bluetooth را انتخاب کن.
  6. منتظر شناسایی دانگل بمان.

نام دانگل ممکن است یکی از این موارد باشد:

OBDII
OBD2
ELM327
V-LINK
OBD Bluetooth

رمزهای احتمالی Pairing

1234
0000
هدف: دستگاه باید در ویندوز با وضعیت Paired یا Connected نمایش داده شود.

مرحله سوم: پیدا کردن پورت COM

  1. کلیدهای Win + X را فشار بده.
  2. Device Manager را باز کن.
  3. قسمت Ports (COM & LPT) را پیدا کن.
  4. پورت مربوط به دانگل بلوتوث را بررسی کن.

نمونه خروجی:

Standard Serial over Bluetooth link (COM5)
Standard Serial over Bluetooth link (COM6)
اگر دو پورت Incoming و Outgoing وجود داشت، معمولاً باید Outgoing را انتخاب کنی.

تنظیم در فایل .env

OBD_PORT=COM6

شماره COM6 صرفاً نمونه است. باید شماره واقعی پورت خروجی دانگل خودت را وارد کنی.

مرحله چهارم: بررسی پورت با Python

فعال‌سازی محیط مجازی

.\venv\Scripts\Activate.ps1

نصب کتابخانه PySerial

pip install pyserial

نمایش پورت‌های موجود

python -c "from serial.tools import list_ports; [print(p.device, '|', p.description) for p in list_ports.comports()]"

خروجی فرضی:

COM3 | Bluetooth Device
COM6 | Standard Serial over Bluetooth link
شماره پورت خروجی دانگل را یادداشت کن.

مرحله پنجم: تست واقعی ارتباط با ELM327

در ریشه پروژه فایل زیر را ایجاد کن: 

test_bluetooth_obd.py

کد تست اتصال

import obd

PORT = "COM6"  # شماره پورت خودت را جایگزین کن

connection = None

try:
    print("Connecting to ELM327...")

    connection = obd.OBD(
        portstr=PORT,
        baudrate=38400,
        fast=False,
        timeout=10,
    )

    print("Connected:", connection.is_connected())
    print("Port:", connection.port_name())

    if connection.is_connected():
        commands = {
            "RPM": obd.commands.RPM,
            "Speed": obd.commands.SPEED,
            "Coolant": obd.commands.COOLANT_TEMP,
            "Engine Load": obd.commands.ENGINE_LOAD,
            "Voltage": obd.commands.CONTROL_MODULE_VOLTAGE,
        }

        for name, command in commands.items():
            response = connection.query(command)
            print(f"{name}: {response.value}")

    else:
        print("Could not connect to vehicle.")

except Exception as error:
    print("Error:", repr(error))

finally:
    if connection is not None:
        connection.close()
        print("Connection closed.")

اجرای تست

python test_bluetooth_obd.py

مرحله ششم: اتصال به پروژه اصلی Car Assistant

اگر تست مستقل موفق بود، فایل .env را تغییر بده: 

OBD_PORT=COM6

سپس پروژه اصلی را اجرا کن:

python main.py
کلاس فعلی OBDClient از تنظیمات پورت استفاده می‌کند؛ بنابراین برای تغییر نوع اتصال، نیازی به تغییر اساسی ساختار پروژه نیست.

مرحله هفتم: عیب‌یابی مشکلات احتمالی

خطا یا وضعیت علت احتمالی
Access is denied پورت توسط برنامه دیگری اشغال شده است.
Port not found شماره COM اشتباه است.
Unable to connect دانگل Pair نشده یا پورت اشتباه است.
No response from adapter مشکل ارتباط سریال یا Baudrate
Unable to connect to vehicle مشکل ارتباط دانگل با ECU خودرو
Connected: False ارتباط کامل برقرار نشده است.

نکات مهم عیب‌یابی

  • برنامه‌های دیاگ دیگر را هنگام تست ببند.
  • شماره COM را دوباره بررسی کن.
  • در صورت نیاز Baudrate را بررسی کن.
  • سوئیچ و سازگاری خودرو با OBD-II را بررسی کن.
  • اگر دانگل BLE باشد، ممکن است پورت COM ایجاد نشود.

مرحله هشتم: نکته مهم درباره پروژه

در اجرای قبلی پروژه روی ویندوز، خطای Pydantic مربوط به diagnostic_status داشتیم.

بنابراین حتی اگر اتصال OBD موفق باشد، ممکن است اجرای main.py همچنان به اصلاح بخش پردازش داده نیاز داشته باشد.

ابتدا اتصال سخت‌افزاری را با test_bluetooth_obd.py تأیید می‌کنیم و سپس مشکلات احتمالی لایه پردازش را بررسی خواهیم کرد.
